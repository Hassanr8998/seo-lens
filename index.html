SchemaPeek vs MozBar

An honest look. SchemaPeek wins on free on-page depth and privacy. MozBar wins on domain metrics and SERP overlays.

MozBar is still better at

  • Domain Authority, Page Authority, Spam Score, backlinks

If DA and backlinks drive your work, keep MozBar or Moz Pro. For on-page audits, SchemaPeek is free and private, and it runs only when you ask. Many people will reasonably use both.

FAQ

Straight answers. No fluff.

Is SchemaPeek really free?

Yes. Every feature on this page is free and there's no account. Paid domain metrics aren't part of SchemaPeek today. Everything listed here is 100% free.

Does it collect my browsing data?

No. It has no analytics, no server and no account. It reads a page only when you open the panel on it. See the privacy policy.

Why does it ask for site access?

SchemaPeek needs site access to read the page you audit, runs nothing until you click, and sends no data. Chrome's side panel doesn't reliably get access to the current tab without it, and the checks you start (broken links, file sizes, status/redirects, robots.txt, sitemap) request those URLs directly from your browser. The only optional permission is webRequest, which records redirect hops; decline it and you just see the final URL.

Does it show Domain Authority?

No. DA is Moz's proprietary metric. On the roadmap: optional bring-your-own-API-key domain metrics, with keys stored only on your computer.

Which browsers?

Chrome (it uses the Chrome side panel). Other Chromium browsers haven't been tested yet.

Can I use it alongside MozBar?

Yes. The two don't conflict.

Wasn't this called SEO Lens?

Yes. SchemaPeek was formerly SEO Lens. Same extension, same Chrome Web Store listing, new name so it isn't confused with other products.
